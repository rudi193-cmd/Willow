# Nestor fleet review — layout playground

Static mock for **fleet-gap** Memory UX. Inspired by layout ideas from a Grok draft
(`~/Desktop/nestor.html`), which was **truncated** (223 lines, no `<body>`) and never
verified in a browser — do not treat that file as working product code.

Open `index.html` in a browser (or `python -m http.server` in this folder).

The live surface is `nestor/nestor/ui_page.py` (same APIs, CSP-safe DOM).
